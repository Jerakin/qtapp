# QtApp

Playground for Qt. Where I investigate how to implement different parts of PySide/PyQt. 


## [qtapp_example_model_update](/src/qtapp_example_model_update/README.md)
Example that illustrates how to update a model from a QThread. 

## [qtapp_example_item_delegate](/src/qtapp_example_item_delegate/README.md)
This example continues by implementing an ItemDelegate to control how the Views item
are rendered.

## [qtapp_example_dynamic_table_size](/src/qtapp_example_dynamic_table_size/README.md)
We continue by adding the ability to change the grid view to a dynamic grid. By resizing
the window the grid is resized automatically to fit it.

## [qtapp_example_dockable](/src/qtapp_example_dockable/README.md)
In this example we add a dockable to the app which displays additional information about
the selected item.

## [qtapp_example_themes_and_icons](/src/qtapp_example_themes_and_icons/README.md)
We dynamically load icons and images and use a QSS to style our app.
